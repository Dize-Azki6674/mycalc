# mycalc

C++23 を利用したシンプルな GUI 電卓アプリ

---

## 概要

mycalc は、基本的な四則演算を行うシンプルな GUI 電卓アプリです。

このプログラムは作者が進めている C++ 学習プロジェクト群の一環として作成されました。

計算処理を GUI から独立させることで、アプリケーションのロジックと表示処理を分離した構成にしています。

---

## 特徴

* 四則演算（加算・減算・乗算・除算）
* 整数および小数の入力
* 計算処理と GUI の分離
* Dear ImGui による GUI
* GLFW によるウィンドウ管理

---

## 動作環境

* C++23 対応コンパイラ
* CMake 4.1 以降
* OpenGL 対応環境

使用ライブラリ:

* Dear ImGui
* GLFW
* Boost

※ プラットフォーム固有の API を利用した処理は実装していません。

---

## ビルド

```bash
mkdir build
cd build

cmake ..
cmake --build .
```

※ vcpkg を利用して依存ライブラリを管理しています。

---

## 実装について

このプロジェクトでは、GUI アプリケーションの開発を主な目的としています。

* Dear ImGui による GUI の構築
* GLFW によるウィンドウ管理
* GUI アプリケーションの設計・実装
* CMake によるビルド管理

---

## 制限事項

* 基本的な四則演算を対象としたシンプルな電卓です。
* 高度な数学関数や複雑な数式の入力には対応していません。
* プラットフォーム固有の API を利用した処理は実装していません。
* 動作環境によっては、別途 OpenGL などの実行環境が必要です。
